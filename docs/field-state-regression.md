# 设备参数状态的设计评审与回归用例

这些合成案例用于评审[设计草案](field-state-design.md)和指导后续实现。使用可控制回复顺序的假邮箱、可回拨的墙钟以及可注入故障的日志。记录每次请求、总线访问、日志提交和状态投影。现有 `_sim` 的 SDO 测试仍期望返回不支持。

## 首版只读

| 对应验收 | 合成输入和步骤 | 应保留的结果 |
|---|---|---|
| A1、A2、A4 | 同一会话先读参数 `p` 得 `[15,0]`（采集序号 7），再读得 `[30,0]`（序号 8）。令 8 的墙钟更早且响应先到，随后交付 7。第三次请求超时。 | 两次成功均可按编号查阅。最新读数为 8，最近尝试为超时，日志页顺序独立于采集顺序。 |
| A3 | 安装 `I1` 运行工程 `P1`，持有会话 `G1` 的延迟响应。切换至 `P2` 并在 `G2` 读同型号、同槽位且 `serial=0` 的设备，再释放 `G1` 响应。另令磁盘工程指纹为 `B`，实际加载指纹为 `A`。 | 旧响应只进入原归属的历史。`G2` 返回弱设备身份。观测归属于实际加载的 `A`，对 `B` 的比较明确报告工程不符。 |
| A5、A8 | `p` 依次读到 15、30、15。提交依赖 `p` 和未读的 `q` 的比较请求。随后改变 `p` 的描述版本，并读取小端字节 `01 00 00 00 00 00 20 00` 的无符号参数。 | `p` 的现值重新匹配，已观测的中间变化仍可查，`q` 为未知。原始字节与各自描述版本可追溯。64 位数 `9007199254740993` 可无损导出和重读。 |
| A7、A10 | 成功提交观测 7 并导出。读到观测 8 后使日志写入失败，保留损坏尾记录，再重启并停止运行时。分别查询已导出的 7 与尚未取回的远端记录。 | 8 的本次读取与保存结果分开，恢复只采用已可靠提交的记录。损坏区间可定位。7 在离线证据包中编号相同，未取回的记录显示暂不可达。查询发出零次设备访问。 |
| A9 | 依次读取 `p`、`q`。分别运行全成功、`q` 超时以及两项之间会话变化三种情况。 | 结果列出各项采样区间、完成情况和会话连续性。已读项仍可追溯，多项同时一致性保持未验证。 |
| A11 | 令一次读取占用邮箱，等待调用方超时后并发发送超出配置预算的刷新请求，并阻塞日志写者。 | 保持一次邮箱事务在途，超预算请求明确返回。扫描与周期 PDO 测试计数持续推进，未完成持久提交的记录无保存回执。 |

## 受控写入接入门槛

以下用例属于 A6。夹具独立计数协议下载和读回。

| 步骤 | 预期 |
|---|---|
| 实际旧值与请求前提不符，或写入意图持久提交失败 | 该请求下载次数为零。 |
| 同一动作 ID 的相同请求并发重送，再在进程重启后重送。用同一 ID 发送不同内容 | 相同请求总下载次数最多一次。内容冲突明确拒绝。 |
| 下发后在确认前终止服务。恢复后读回恰好等于目标值 | 原动作进入待核验记录。回读产生新观测，原事务归因保持未知，恢复下载次数为零。 |

## 审核记录

每条用例保留假邮箱事件序列、采集与日志顺序、响应状态及导出后的观测编号。将当前主线已有行为、上述设计目标和后续产品验收结果分列。
